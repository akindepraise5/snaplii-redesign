Agent-to-Merchant payments (A2M)

Let AI agents pay.Without your card.

Snaplii gives agents permission to spend from a prepaid balance, within limits you set, at gift-card merchants across Canada and the US. Gift cards are accepted at 500,000+ locations.

Safety and control,
built in.

Built by a team with a decade in licensed payments. Powered by licensed payment partners.

Prepaid balance only

Agents spend only from Snaplii Cash. No credit card is ever charged.

Scoped keys

Each API key gets a scope (PAY_READ, PAY_WRITE, P2P or ALL) and a name.

Spending limits

Set a daily limit per key for gift cards. Transfers have their own rolling 24-hour limit.

Revoke anytime

Keys are created and revoked only in the Snaplii app, never by the agent.

Keys never stored

The API key is exchanged for a short-lived session token. The token goes in the OS keychain where available.

Built-in pauses

Agents quote before every purchase, and transfers can be cancelled for about 5 minutes before they send.

Gift card purchases charge immediately, and bill payments can't be undone once sent. The per-key daily limit applies to gift cards; bill payments aren't covered by it.

What agents can do.

Four jobs, each one a few commands or MCP tool calls.

Buy gift cards

Browse categories and brands, check cashback, quote and buy, at gift cards accepted at 500K+ locations.

Pay bills

Find a biller, save the details, preview the price with vouchers applied, then pay.

Send transfers

Send money to a phone number, with a ~5-minute cancel window.

Check balance and rewards

Get the spendable balance, owned gift cards and exact cashback for an amount.

Quickstart.

From a new API key to your first purchase in three steps.

  1. 1

    Create an API key

    In the Snaplii app (iOS or Android), go to:

    1. More
    2. Payment Methods
    3. AI Payment Management
    4. + New API Key

    Choose a scope and set a spending limit. The key is shown only once.

  2. 2

    Install

    Python 3.9+
    pipx install snaplii-clisnaplii init
    OpenClaw plugin v1.14.2
    openclaw plugins install clawhub:snaplii-a2m-mcp@latest
    MCP server via uv
    uvx snaplii-mcp@0.20.3

    Every CLI command prints JSON, so any agent that can run a shell command can use it.

  3. 3

    Connect and make your first call

    CLI
    snaplii initsnaplii browse tagssnaplii balance --country CAsnaplii quote --item-id <cardBrandId-cardTemplateId> --price 50snaplii purchase --item-id <cardBrandId-cardTemplateId> --price 50

    Copy --item-id exactly from snaplii browse brand, and use the same value for quote and purchase.

Why this approach.

Which regions are supported?

Canada (CAD) and the United States (USD). The catalogue is scoped to the account's country, set at login.

Which AI clients can use it?

Any MCP client, including OpenClaw, plus any agent that can run shell commands through the CLI.

Does the agent ever see my card?

No. It spends from a prepaid Snaplii Cash balance using a scoped key.

How do I stop an agent?

Revoke its key in the Snaplii app. You can also lower its spending limit.

Is it open source?

Yes. The CLI and MCP server are Apache 2.0 licensed on GitHub.

How much does it cost?

Pricing for integrations isn't published. Use Talk to us to discuss your use case.

Can merchants or platforms partner with Snaplii?

Yes, through the partnership form.
