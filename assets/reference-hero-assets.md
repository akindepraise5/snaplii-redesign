# Reference hero assets

The current hero is implemented as responsive HTML/CSS. The supplied website image was a layout and photographic reference; it is not embedded as a screenshot.

Original photos were generated with the built-in image-generation tool, then compressed to WebP for the page. PNG originals are preserved.

- `snaplii-hero-friends.webp` — 1536 × 1024, wide photo panel.
- `snaplii-hero-portrait.webp` — 1122 × 1402, portrait photo panel.
- `snaplii-app-qr.svg` — generated with ReportLab's QR encoder for `https://snaplii.onelink.me/leIp/website`. The same destination is used by the clickable download panel and main hero CTA.
